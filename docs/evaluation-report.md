## 1. 检索评测

### 题集与方法

题目与标注证据 ID 见 `evaluation/router_questions.json`，分为两部分：

| 题集 | 资料内题 | 库外题 | 用途 |
|---|---:|---:|---|
| calibration | 6 | 6 | 只用于选择相关性阈值 |
| holdout | 16 | 6 | 阈值固定后评估，不再据此调参 |

阈值选择方法：只在校准集上最小化"库外误接受 + 资料内误拒绝"，平局时取更高阈值。当前阈值为 raw logit `-0.8163`，记录在 `data/router/retrieval_policy.json`。

Recall@3 是标注证据出现在前 3 条结果中的比例；MRR 衡量第一条正确证据的排名。两者都只统计资料内题。

### 解读

- 在这个小库上，三种召回方式的 Recall@3 已经接近，差异主要体现在排序：重排把所有正确证据都排到了第一位。
- 22 道保留题是手工编写的小样本，并且在初版验收后作为固定回归集继续使用，不是全新的独立泛化测试。
- 相关性分数是 raw logit，表示相关程度，不是答案正确的概率。

## 2. 服务接口检查

原始结果：`evaluation/router_service_results.json`，13/13 通过。

在真实启动的 FastAPI 服务上检查：健康检查、旧请求形状（只传 question + top_k）、显式设备字段、缺少设备信息、未收录的型号/版本/地区、参数冲突、库外问题拦截、422 参数校验，并核对每条返回证据都属于请求的设备范围。同时使用 Agent 项目中原有的 HTTP 适配器调用本服务，确认返回字段兼容。

这项检查验证的是接口契约，不是完整的在线 Agent 回归。

## 3. 生成质量评测

审核口径与指标定义见 [`generation-evaluation.md`](generation-evaluation.md)。

### 初版在线验收

`evaluation/generation_initial_review.json` 记录了初版在 Windows 本机的 6 类在线回答（Wi-Fi 修改、AP 模式、恢复出厂、固件升级、无线断连、库外问题）的定性检查。Wi-Fi 题通过；其余题发现引用归属、资料缺漏、检索范围表述和拒答措辞等问题。

据此做了以下修订：

- 补全两种恢复出厂方式的位置、用途和影响范围，补充普通重启保留配置的通用说明；
- 固件升级的硬件版本、购买地区和有线升级注意事项单独引用官方 FAQ 2796；
- 补全无线断连的前置条件、排查顺序与 Smart Connect 菜单；
- 提示词明确区分设备事实、系统追问和"证据不足"声明，证据不足只针对本次检索结果；
- 库外拒答改为中性的服务范围说明。

修订后重建索引并只用校准集重新选择阈值，上面第 1 节的检索结果即为修订版结果。
